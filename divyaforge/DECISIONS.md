# DECISIONS.md — choices the PRD/kickoff left open

A running log. Anything cultural is **flagged for Iconography Council review** rather than
treated as settled.

| # | Decision | Rationale / flag |
|---|---|---|
| D1 | DivyaForge lives in `divyaforge/` inside the WDS-Native repo | This session is bound to this repo+branch. The subdirectory is fully self-contained; recommend extracting to a dedicated repo before M1. |
| D2 | Placeholder **parts** are real GLB files generated by `scripts/generate-placeholder-assets.mjs`; the renderer only ever loads `meshUrl` | Guarantees the “zero code changes to swap in artist parts” requirement — swapping = new files + new catalog rows. The **body** is procedural primitives (kickoff explicitly allows this for the placeholder humanoid). |
| D3 | Storage adapter with **demo mode**: no Supabase env → localStorage saves + config-encoded share links (`/d/cfg_<base64url>`); with env → Postgres rows (`/d/<shortcode>`) | Repo must run with `npm i && npm run dev` and still exercise every flow. Same UI code paths either way. |
| D4 | Pricing formula: `base(material) × sizeMult + volumeCharge + Σ part.priceVolume × rate`, sub-cubic size multipliers (1.0 / 1.55 / 2.35), prices rounded **up** to a ₹…9 ending | PRD gives bases + “volume/size/complexity” only. Sub-cubic because fixed costs don’t scale with volume. Constants isolated in one file for tuning. |
| D5 | Seed iconography rules: ankusha → right hands, pasha → left hands, modak → left hands, unique items max 1, `fierce`-tagged items denied on `saumya` deities | Based on common Ganapati iconography conventions. **⚑ Cultural — needs advisor confirmation**; encoded as data rows, trivially editable. |

| D7 | `name_hi` Devanagari strings written for well-known terms (गणेश, मोदक, अंकुश, पाश, कमल…) | Schema requirement met with real text, but **⚑ placeholder quality — needs native review** before display is promoted beyond M0. |
| D8 | Auth: Supabase email+password (no OAuth in M0). Demo mode uses a local pseudo-profile so Share/Buy flows are testable | Fewest external setup steps for reviewers. |
